# DMARCguard pour YunoHost

Ce dépôt contient une proposition de packaging YunoHost pour :

- Source amont : https://github.com/dmarcguardhq/dmarcguard
- Identifiant du paquet : `dmarcguard`
- Format de packaging : `2`

Le paquet installe DMARCguard derrière nginx, compile le frontend et le backend depuis les sources, et démarre un service systemd.
